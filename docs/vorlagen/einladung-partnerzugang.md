# Vorlage: Einladung zum Partner-Zugang

Wird zusätzlich zur automatischen WordPress-E-Mail („Zugangsdaten / Passwort festlegen“) verschickt, nachdem der Zugang unter Benutzer → Partner-Zugänge angelegt wurde. Platzhalter in eckigen Klammern ersetzen.

---

**Betreff:** Ihr Zugang zu Merzenich Aktuell ist eingerichtet

Guten Tag [Name],

für [Organisation] ist jetzt ein Zugang zu Merzenich Aktuell eingerichtet. Damit können Sie Ihre Beiträge selbst schreiben und zur Veröffentlichung einreichen.

**Anmelden – in vier Schritten**

1. Öffnen Sie die E-Mail von WordPress mit dem Betreff „Zugangsdaten“ bzw. „Passwort festlegen“. Sie ist an [E-Mail-Adresse] gegangen. Bitte auch im Spam-Ordner nachsehen.
2. Klicken Sie auf den Link darin und legen Sie ein eigenes Passwort fest. Der Link ist nur begrenzt gültig; ist er abgelaufen, nutzen Sie auf der Anmeldeseite „Passwort vergessen?“.
3. Melden Sie sich an unter: [Link zur Anmeldung, z. B. Adresse der Website + /wp-admin/]
   Ihr Benutzername: [Benutzername]
4. Nach der Anmeldung sehen Sie nur Ihren eigenen Bereich.

**Einen Beitrag einreichen**

- [Für Nachrichten: „Beiträge → Neuen Beitrag erstellen“ / für Unternehmen zusätzlich „Unternehmen“ und „Werbung“ / für Makler: „Immobilien“ – Unzutreffendes streichen]
- Titel und Text schreiben, bei Bedarf ein Foto als Beitragsbild hochladen.
- Hat der Beitrag ein Foto: Haken bei „Fotoerlaubnis“ setzen. Ohne diesen Haken bleibt der Beitrag Entwurf.
- Auf die Schaltfläche zum Einreichen klicken (je nach Editor „Zur Überprüfung einreichen“ oder ähnlich). Veröffentlicht wird erst nach der Prüfung.

Die Redaktion prüft jeden Beitrag vor der Veröffentlichung. Sie erhalten eine E-Mail, sobald er freigegeben ist, oder eine kurze Begründung, falls er so nicht erscheinen kann. Veröffentlichte Beiträge können Sie nicht mehr selbst ändern; schreiben Sie uns in diesem Fall kurz.

[Nur für Unternehmen:] Ihr Zugang umfasst [Anzahl] gleichzeitig laufende Anzeige(n) auf folgenden Plätzen: [Plätze]. Auch Anzeigen werden vor der Veröffentlichung von der Redaktion geprüft. Weitere Plätze: Preis auf Anfrage.

Bei Fragen antworten Sie einfach auf diese E-Mail.
