# Fotowunschliste für die Bildpools

Stand: 07.10.2026. Diese Liste geht an ChatGPT, damit die Bildpools in WordPress vollständig werden. Merzenich Aktuell zeichnet keine eigenen Ersatzgrafiken mehr. Wo kein passendes Foto da ist, bleibt eine Karte ohne Bild.

## So sollen die Fotos sein

- **Format:** Querformat, mindestens 1600 Pixel breit, am besten 3:2 oder 16:9. JPG oder WebP.
- **Wirkung:** Fotorealistisch, natürliches Licht, keine Comic-, Grafik- oder Illustrationsoptik.
- **Ort:** Deutschland, ländliches Rheinland (Kreis Düren). Keine Hochhäuser, keine Berge, keine Palmen, keine ausländischen Schilder.
- **Ohne Text:** Keine lesbaren Kfz-Kennzeichen, Ortsnamen, Straßenschilder, Firmenlogos, Markennamen, Wappen oder Vereinslogos.
- **Personen:** Keine erkennbaren Gesichter, schon gar nicht von Menschen in einer Notlage. Personen nur von hinten, angeschnitten oder unscharf im Hintergrund.
- **Einsatzfahrzeuge:** Allgemein gehalten, ohne Ortsaufschrift (also kein „Feuerwehr Musterstadt“).
- **Herkunft**, eine von zwei Möglichkeiten:
  1. Echte Fotos mit freier Lizenz, zum Beispiel Pexels, Unsplash oder Wikimedia Commons (CC0, CC BY, CC BY-SA). Fotograf, Lizenz und Link zur Quelle notieren.
  2. Von ChatGPT erzeugte Bilder. Sie werden immer als „Symbolbild · KI-generiert“ gekennzeichnet.

## So kommen die Fotos in WordPress

1. **Medien → Datei hinzufügen** und das Foto hochladen.
2. Im Bild rechts ausfüllen:
   - **Alternativtext:** was zu sehen ist, z. B. „Streifenwagen von hinten auf einer Landstraße“.
   - **Fotograf / Urheber:** Name des Fotografen, oder „KI-generiert (ChatGPT)“.
   - **Quelle:** Link zum Foto (Pexels, Unsplash, Commons), oder „ChatGPT, erstellt am TT.MM.JJJJ“.
   - **Nutzungsgrundlage:** die Lizenz, z. B. „Pexels-Lizenz“, „CC BY-SA 4.0“, oder „KI-generiert, Symbolbild“.
3. Im Feld **„Bildpools“** des Bildes den Pool eintragen, z. B. „polizei“.
4. **Rechteprüfung** auf „Geprüft – Nutzung freigegeben“ stellen. Das geht erst, wenn Urheber, Quelle und Nutzungsgrundlage ausgefüllt sind.

Danach zeigt **Medien → Bildpools**, wie viele Fotos je Pool noch fehlen.
